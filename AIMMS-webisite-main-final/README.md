# AIMMS Bright Redesign

A clean, bright, professional static website for the Armenian-International Mining and Metallurgy Society.

## Files

- `index.html` — Home page
- `mission.html` — Mission page
- `steering-committee.html` — Steering Committee page
- `events.html` — Events page with JavaScript filtering
- `contact.html` — Separate Contact Us page
- `assets/aimms-logo.svg` — Clean transparent vector logo used in the header and footer
- `assets/aimms-logo-transparent.png` — High-resolution transparent PNG logo
- `assets/aimms-icon.svg` — Transparent icon/favicon version
- `assets/aimms-icon.png` — PNG icon version
- `css/styles.css` — Main design system and responsive layout
- `js/script.js` — Mobile menu, reveal animations, event filters, mailto contact form

## GitHub Pages upload

1. Create a GitHub repository.
2. Upload all files and folders exactly as they are.
3. Go to **Settings → Pages**.
4. Set source to **Deploy from a branch**.
5. Choose the `main` branch and `/root` folder.
6. Save.
